Step-by-step procedures for common operations and incidents. These are the day-to-day "how do I…" answers.

## RB-01 — Register the council with an MCP client

```bash
# Claude Code
claude mcp add council npx agents-council@latest mcp
# …with a fixed identity (drops the agent_name arg from tools):
claude mcp add council -s user -- npx agents-council@latest mcp -n Opus

# Gemini / Codex / amp
gemini mcp add council npx agents-council@latest mcp
codex  mcp add council npx agents-council@latest mcp
amp    mcp add council npx agents-council@latest mcp
```
**Verify:** the client lists `council` among its MCP servers and the seven tools appear.

## RB-02 — Run a council from start to conclusion (headless)

1. Agent A: `start_council(request, agent_name)` → note the returned `session_id` and assigned name.
2. Share `session_id` with Agent B (out of band).
3. Agent B: `join_council(session_id, agent_name)` → read the request.
4. Agent B: `send_response(session_id, content)`.
5. Agent A: `get_current_session_data(session_id, cursor)` repeatedly, advancing the cursor.
6. Agent A: `close_council(session_id, conclusion)` when satisfied.

## RB-03 — Open the desktop Council Hall

```bash
council          # default launch
council chat     # compatibility alias (same desktop)
```
First run prompts for your name at the Gate; it persists to localStorage. If launch fails, see RB-08.

## RB-04 — Summon an agent

**UI:** Hall → "Summon Agent" → pick agent (Claude/Codex), optional model/reasoning effort → confirm.

**MCP:** `summon_agent({ agent: "Claude" | "Codex", model? })` (requires an active session with an open request).

**Prerequisites:**
- Claude: `claude` installed and authenticated once.
- Codex: `codex login` completed.

**Verify:** new feedback from the summoned agent appears in the session.

**Debug failures:** set `AGENTS_COUNCIL_SUMMON_DEBUG=1`, retry, and inspect `./summon-debug.log` (look for `summon_error`).

## RB-05 — Run the Model Council

```bash
export OPENROUTER_API_KEY="..."
codex login                              # for the ChatGPT member
council solve "Decide the best architecture for ..."
# or as JSON:
council solve --json "..."
```
Or via MCP: `run_model_council({ prompt })`.

**Verify:** output reports `consensus.reached`, `ratifiedBy`, `blockedBy`. A *blocked* result is a valid outcome (genuine disagreement), not an error.

## RB-06 — Inspect / audit current state

```bash
jq . ~/.agents-council/state.json                       # full state
jq '.sessions[] | {id,status,createdAt}' ~/.agents-council/state.json
jq -r '.feedback[] | "\(.author): \(.content[0:80])"' ~/.agents-council/state.json
```

## RB-07 — Recover from a stuck file lock

Symptom: `"Timed out waiting for file lock"`.
1. Confirm no council process is mid-write (the lock self-heals after 30 s of staleness).
2. If it persists and no writer is running, remove the stale lock:
   ```bash
   rm -f ~/.agents-council/state.json.lock ~/.agents-council/config.json.lock
   ```
3. Retry the operation.

## RB-08 — Desktop runtime won't launch

Symptom: `"Desktop runtime is not configured for this invocation."` or an early-exit error.
1. From a source checkout, run `bun run desktop:dev` directly to see errors.
2. Confirm the install carried the platform package's desktop artifacts.
3. As an override, set `COUNCIL_DESKTOP_COMMAND` (and `COUNCIL_DESKTOP_ARGS`) to a known-good executable.
4. Reinstall: `npm install -g agents-council@latest`.

## RB-09 — Corrupt / unreadable state file

Symptom: `"State file is invalid JSON…"` or `"State file contains an unsupported schema."`
1. Back up the bad file: `cp ~/.agents-council/state.json ~/state.bad.json`.
2. Fix the JSON by hand if recoverable (it is plaintext), or
3. Remove it to start fresh: `rm ~/.agents-council/state.json` (a new empty v2 state is created on next access).
4. See [7.5 Disaster Recovery](7.5_disaster_recovery.md) for restoring from backup.

## RB-10 — Refresh summon model lists

**UI:** Settings → refresh models. **Effect:** re-fetches Claude models (Agent SDK) and Codex models (`app-server`), updating `config.json` `summonModelsCache`. If discovery times out (8 s), the prior cache / config-default is retained.

## RB-11 — Move the state file

```bash
export AGENTS_COUNCIL_STATE_PATH="/path/to/state.json"
# config.json is created as a sibling automatically
```
Set this before launching any council process; existing data is not migrated automatically — copy `state.json` and `config.json` to the new location first if needed.

## RB-12 — Upgrade / pin / rollback

```bash
npm install -g agents-council@latest      # upgrade
npm install -g agents-council@<version>   # pin / rollback
# MCP-only users: change the version in the registered command
```
