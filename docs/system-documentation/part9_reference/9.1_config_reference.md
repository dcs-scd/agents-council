The complete reference for every environment variable, CLI flag, and config-file field.

## Environment Variables

### Core / state
| Variable | Default | Description |
|----------|---------|-------------|
| `AGENTS_COUNCIL_STATE_PATH` | `~/.agents-council/state.json` | State file path; `config.json` is always its sibling. `~`/`~/` expanded, relative paths resolved against CWD |

### Summon
| Variable | Default | Description |
|----------|---------|-------------|
| `CLAUDE_CODE_PATH` | `claude` (PATH) | Path to the Claude Code executable (config `claudeCodePath` overrides) |
| `CODEX_PATH` | bundled Codex | Path to the Codex CLI (config `codexPath` overrides) |
| `AGENTS_COUNCIL_SUMMON_DEBUG` | unset | `1`/`true`/`yes` → append JSONL trace to `./summon-debug.log` |

### Model Council
| Variable | Default | Description |
|----------|---------|-------------|
| `OPENROUTER_API_KEY` | — (required for model council) | Bearer key for Kimi & DeepSeek via OpenRouter |
| `OPENROUTER_HTTP_REFERER` | unset | Optional `HTTP-Referer` header for OpenRouter |
| `AGENTS_COUNCIL_KIMI_MODEL` | `moonshotai/kimi-k2.6` | Kimi model id |
| `AGENTS_COUNCIL_DEEPSEEK_MODEL` | `deepseek/deepseek-v4-pro` | DeepSeek model id |
| `AGENTS_COUNCIL_CHATGPT_MODEL` | `gpt-5.5-pro` | ChatGPT (Codex) model name |

### Desktop launch (advanced)
| Variable | Default | Description |
|----------|---------|-------------|
| `COUNCIL_DESKTOP_COMMAND` | unset | Override executable for the desktop runtime |
| `COUNCIL_DESKTOP_ARGS` | unset | Space-separated args for the override |
| `COUNCIL_DESKTOP_LAUNCH_SOURCE` | set by launcher | `default` \| `chat` (passed to the desktop process) |
| `AGENTS_COUNCIL_VERSION` | `0.4.0` | Version stamped into the Electrobun build |

### Build / runtime
| Variable | Description |
|----------|-------------|
| `__COUNCIL_VERSION__` | Compile-time define for the CLI version |
| `npm_package_version` | Runtime version fallback when the define is absent |

## CLI Reference

```text
council                            # launch desktop (default)
council mcp [options]              # start MCP stdio server
council chat [options]             # compatibility alias → desktop
council solve <prompt...> [--json] # run the Model Council, print consensus
council -v | --version            # print version
council --help                    # usage
```

### `council mcp` options
| Flag | Default | Description |
|------|---------|-------------|
| `-f, --format <markdown\|json>` | `markdown` | Tool output format |
| `-n, --agent-name <name>` | (none) | Bake in a default identity; removes `agent_name` from `start_council`/`join_council` |

### `council chat` options (deprecated, ignored with a warning)
| Flag | Description |
|------|-------------|
| `-p, --port <number>` | Ignored; chat now launches desktop |
| `--no-open` | Ignored; chat now launches desktop |

### `council solve` options
| Flag | Description |
|------|-------------|
| `<prompt...>` | The problem to deliberate (joined with spaces) |
| `--json` | Print the full structured `ModelCouncilResult` as JSON instead of formatted text |

## `config.json` Fields

Location: sibling of the resolved state path (default `~/.agents-council/config.json`).

| Field | Type | Description |
|-------|------|-------------|
| `lastUsedAgent` | `string \| null` | Default agent for the next summon |
| `agents` | `Record<string, {model, reasoningEffort}>` | Saved per-agent model + reasoning effort |
| `agents[name].model` | `string \| null` | Saved model for that agent |
| `agents[name].reasoningEffort` | `string \| null` | Saved reasoning effort (Codex) |
| `claudeCodePath` | `string \| null` | Tool-path override for `claude` |
| `codexPath` | `string \| null` | Tool-path override for `codex` |
| `summonModelsCache` | `Record<string, {models, updatedAt}>` | Cached discovered models per agent |
| `summonModelsCache[a].models[]` | `SummonModelInfo[]` | `{value, displayName, description, supportedReasoningEfforts[], defaultReasoningEffort}` |
| `summonModelsCache[a].updatedAt` | ISO string | When the list was fetched |

## `state.json` Fields

| Field | Type | Description |
|-------|------|-------------|
| `version` | number | Schema version (`2` current) |
| `activeSessionId` | `string \| null` | The focused session |
| `sessions[]` | `CouncilSession[]` | `{id, status, createdAt, currentRequestId, conclusion}` |
| `requests[]` | `CouncilRequest[]` | `{id, sessionId, content, createdBy, createdAt, status}` |
| `feedback[]` | `CouncilFeedback[]` | `{id, sessionId, requestId, author, content, createdAt}` |
| `participants[]` | `CouncilParticipant[]` | `{sessionId, agentName, lastSeen, lastRequestSeen, lastFeedbackSeen}` |

See [Appendix B](../appendices/B_schemas.md) for full JSON schemas.
