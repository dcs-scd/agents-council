# 9.3 Glossary

> **Last Updated:** 2026-05-22
> **Related:** [1.3 Key Concepts](../part1_understanding/1.3_key_concepts.md) · [3.1 Data Model](../part3_data/3.1_data_model.md) · [4.3 Events](../part4_interfaces/4.3_events.md)

---

Complete alphabetical terminology reference.

| Term | Definition |
|------|------------|
| **Active session** | The single session referenced by `activeSessionId`; the default target and the focus of the desktop Hall |
| **Agent name** | A self-declared, server-resolved identity; collisions get `#N` suffixes |
| **`agents-council`** | The system: an MCP-based bridge + desktop app for cross-agent collaboration |
| **Atomic write** | Persisting via a temp file + `fsync` + `rename`, so the live file is never partially written |
| **Bridge** | The face-agnostic action layer (`chat/bridge/actions.ts`) shared by the HTTP and Electrobun RPC faces |
| **`BridgeApiError`** | An error carrying an HTTP status, thrown by bridge actions on bad input |
| **`BridgeResult<T>`** | The `{ok:true,data}` / `{ok:false,error}` shape returned by the Electrobun RPC bridge |
| **Candidate consensus** | The evolving draft answer in a Model Council deliberation, marked by `CANDIDATE_CONSENSUS:` |
| **Chair-free** | The Model Council property that no single member synthesizes or decides the outcome |
| **Conclusion** | The sealed summary recorded when a session closes (`author`, `content`, `createdAt`) |
| **Config (`config.json`)** | Summon settings + model cache + tool paths; sibling of the state file |
| **Council** | The overall multi-agent collaboration; concretely an active session + its request/feedback/participants |
| **`CouncilService`** | The core domain interface implementing the session lifecycle |
| **`CouncilState`** | The full state root (version, activeSessionId, sessions, requests, feedback, participants) |
| **Cursor** | A feedback-id pagination token; `next_cursor` = last-seen feedback id |
| **Deliberation round** | One pass where each Model Council member critiques peers and emits a candidate consensus (≤4 rounds) |
| **Desktop face** | The Electrobun Council Hall app — the default human interface |
| **DTO** | Data Transfer Object — the snake_case wire types distinct from camelCase domain types |
| **Electrobun** | The Bun-native cross-platform desktop runtime (bun process + native webview) |
| **Face** | One of the three delivery surfaces: MCP stdio, Electrobun desktop, CLI |
| **Feedback** | One agent's response to the current request |
| **File lock** | The `.lock` sidecar coordinating writers (10 s wait, 30 s stale reclaim) |
| **`FileCouncilStateStore`** | The state store implementation over `state.json` |
| **Gate** | The "Announce Yourself" screen capturing the operator's name before the Hall |
| **Hall (Council Hall)** | The main desktop UI: sidebar + active-session header + voice stream + composer |
| **Integrity check** | `assertCouncilStateIntegrity` — referential validation run on read and before write |
| **MCP** | Model Context Protocol; the council's primary headless transport (over stdio) |
| **Model Council** | The chair-free three-agent consensus engine (`run_model_council` / `council solve`) |
| **Objective Consensus Directive** | The shared "optimize for accuracy, don't validate the premise" prompt fragment |
| **OpenRouter** | The API used for the Kimi and DeepSeek council members |
| **Participant** | A record of an agent in a session (name + last-seen / progress markers) |
| **Pending participants** | Participants who have not yet answered the current request |
| **Polling** | How headless agents fetch new feedback (`get_current_session_data` + cursor) |
| **Ratification** | Each Model Council member's independent `CONSENSUS: ACCEPT|BLOCK` vote on the converged candidate |
| **Read-only sandbox** | The constraint on summoned agents: read tools only, no writes, no network (Codex) |
| **Request** | The matter put before the council |
| **RPC bridge** | The Electrobun renderer ⇄ bun-process transport |
| **Session** | A single conversation container (`active` / `closed`) |
| **`state.json`** | The single JSON file holding all council state |
| **`state-changed`** | The payload-free event signaling UIs to re-poll, emitted by the watcher |
| **Summon** | Bringing a fresh Claude or Codex agent into the active session to contribute once |
| **`SummonModelInfo`** | A discovered model's metadata (value, displayName, description, reasoning efforts) |
| **Voice stream** | The ordered feedback list rendered in the Hall |
| **Watcher** | The `fs.watch`-based state-change detector that drives UI updates |
