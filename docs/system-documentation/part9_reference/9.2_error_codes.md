# 9.2 Error Code Registry

> **Last Updated:** 2026-05-22
> **Related:** [7.2 Alerting](../part7_operations/7.2_alerting.md) · [7.4 Runbooks](../part7_operations/7.4_runbooks.md) · [2.5 Cross-Cutting Concerns](../part2_architecture/2.5_cross_cutting.md)

---

`agents-council` does not use numeric error codes — it throws `Error`s with human-readable messages, and the HTTP face attaches HTTP status codes via `BridgeApiError`. This registry catalogs the messages by source, their cause, and the fix.

## Domain / Service Errors (`CouncilService`)

| Message | Cause | Fix |
|---------|-------|-----|
| `No active session.` | `closeCouncil`/`sendResponse`/summon with no active session | `start_council` first, or target an explicit `session_id` |
| `Session not found.` | `session_id` doesn't exist | Use a valid id from `list_sessions`/`listSessions` |
| `Council session is already closed.` | `closeSession` on a closed session | Nothing to do — it is already sealed |
| `Council session is closed.` | `sendResponseToSession` on a closed session | Reopen by starting a new session |
| `No active request.` | Sending with no open request on the session | Ensure the session has an open request |

## Persistence / State Errors (`fileStateStore`, `fileStore`)

| Message | Cause | Fix |
|---------|-------|-----|
| `State file is invalid JSON at <path>. Fix or remove the file and retry.` | `state.json` is malformed | Repair the JSON or remove it (RB-09) |
| `State file contains an unsupported schema.` | File is neither v1 nor v2 | Restore a backup or rebuild a v2 skeleton |
| `Timed out waiting for file lock` | Lock held > 10 s | Wait for 30 s stale-reclaim or remove `state.json.lock` (RB-07) |
| `Duplicate session id detected: <id>` | Integrity check on a hand-edited file | Remove the duplicate session |
| `activeSessionId does not reference an existing session: <id>` | Dangling active pointer | Set `activeSessionId` to a real id or `null` |
| `Request <id> references unknown session <id>` | Orphan request | Add the session or remove the request |
| `Feedback <id> references unknown request <id>` | Orphan feedback | Add the request or remove the feedback |
| `Feedback <id> session (...) does not match request session (...)` | Cross-session feedback | Correct the `sessionId`/`requestId` linkage |
| `Duplicate participant detected: <session::name>` | Repeated participant key | Deduplicate participants |
| `Session <id> currentRequestId <id> belongs to session <id>` | Mis-linked current request | Fix `currentRequestId` to a request in that session |
| `Legacy <field> must be ...` | v1 migration validation failure | Fix the legacy field shape |

## MCP Tool Errors (`mcp/server.ts`)

These are returned as `CallToolResult { isError: true }`:

| Message | Cause |
|---------|-------|
| `agent_name is required for start_council.` | No name and no `-n` default |
| `session_id is required for <tool>.` | Missing `session_id` |
| `get_current_session_data needs a stored agent name. Call join_council (or start_council) once, then retry.` | Polling before identifying |
| `send_response needs a stored agent name. Call join_council (or start_council) once, then retry.` | Sending before identifying |
| `Agent name not set for <tool>. Call start_council or join_council first.` | Close/identity-dependent call before identifying |
| Zod validation errors | Schema violation (empty string, unknown field via `.strict()`, unsupported `model`) |
| `Model is not supported for this agent.` / `Model override is unavailable without a cached model list.` | `summon_agent` `model` not in the cached list |

## Summon Errors (`summon.ts`)

| Message | Cause |
|---------|-------|
| `Unsupported agent.` | `agent` not `Claude`/`Codex` |
| `No active council session.` | Summon with no active session |
| `No active request.` | Summon with no open request |
| `Claude did not submit a response.` | Summoned Claude produced no feedback |
| `Codex did not return a response.` | Summoned Codex returned empty `finalResponse` |
| `Summon failed to return a result.` / `Claude summon failed.` | SDK returned no/failed result (`resolveSummonResultError`) |
| `Timed out.` | Model discovery exceeded 8 s |

## Model Council Errors (`modelCouncil.ts`)

| Message | Cause |
|---------|-------|
| `prompt is required.` | Empty prompt |
| `OPENROUTER_API_KEY is required for Kimi and DeepSeek council members.` | Missing key |
| `<member> OpenRouter request failed: <detail>` | Non-OK OpenRouter response |
| `<member> returned an empty OpenRouter response.` | Empty content from OpenRouter |
| `<member> returned an empty Codex response.` | Empty `finalResponse` from the Codex member |

## Bridge / HTTP Errors (`bridge/actions.ts`, `chat/server.ts`)

`BridgeApiError(status, message)` maps to HTTP status (default 500):

| Status | Message | Cause |
|--------|---------|-------|
| 400 | `Request body must be a JSON object.` | Non-object payload |
| 400 | `"<field>" is required.` | Missing required field |
| 400 | `"<field>" must be a string.` / `... or null.` | Wrong field type |
| 400 | `Invalid JSON body.` | Unparseable request body |
| 400 | `Unsupported agent.` | Bad summon agent |
| 400 | `"status" must be one of: all, active, closed.` | Bad list filter |
| 404 | `Not found.` | Unknown route/method |
| 500 | (mapped error message) | Any non-Bridge error |

## CLI / Launcher Errors

| Message | Cause |
|---------|-------|
| `Startup error: --format expects 'markdown' or 'json'.` | Bad `--format` |
| `Startup error: --agent-name expects a value.` | Empty `--agent-name` |
| `Unknown command: <cmd>` | Unrecognized subcommand (prints help, exits 1) |
| `Failed to start MCP server: <detail>` | MCP startup failure |
| `Failed to run model council: <detail>` | `solve` failure |
| `Desktop runtime is not configured for this invocation. ...` | No desktop runtime found (RB-08) |
| `Desktop runtime exited with code <n>. <stderr>` | Desktop crashed within 400 ms of launch |
| `Port <n> is already in use. ...` | HTTP chat server `EADDRINUSE` |

## Convention

> Errors are written for the human who will read them, with the remedy embedded where possible. There are no opaque codes to look up — the message *is* the documentation.
