Getting a development environment running. The project is Bun-native; Node.js is needed only for npm publish/install-parity checks.

## Prerequisites

| Tool | Why |
|------|-----|
| **Bun** (latest) | Primary runtime, bundler, test runner, package manager |
| **Node.js** | npm publish + install-sanity parity checks |
| `claude` CLI (optional) | To exercise Summon Claude |
| `codex` CLI (optional) | To exercise Summon Codex / Model Council ChatGPT |
| `OPENROUTER_API_KEY` (optional) | To exercise the Model Council (Kimi/DeepSeek) |

## Clone & Install

```bash
git clone https://github.com/MrLesk/agents-council.git
cd agents-council
bun install        # also installs Husky git hooks via "prepare"
```

## Run From Source

```bash
# MCP server from source
bun run cli mcp                       # = bun src/cli/index.ts mcp
bun run cli mcp -- -n Opus -f json    # with a fixed name + JSON output

# Model Council from source
bun run cli solve "Decide the best architecture for X"

# Desktop app (Electrobun dev runtime)
bun run desktop:dev
```

`bun run cli` runs `src/cli/index.ts` directly; subcommands and flags follow.

## Build

```bash
bun run build                 # → dist/council (or dist/council.exe on Windows)
bun run desktop:build         # Electrobun desktop artifacts
bun run desktop:build:stable  # stable-channel artifacts → ./artifacts/stable-<platform>-<arch>-*
```

The compiled CLI is a Bun standalone binary; the version is injected at build time via the `__COUNCIL_VERSION__` define (the release pipeline sets it from the git tag).

## Wiring Into a Local MCP Client

To test the council against a real client during development, point the client at the source CLI:

```bash
# Example: register the source build with Claude Code
claude mcp add council-dev -- bun run --cwd /path/to/agents-council cli mcp
```

Or build first and register the binary:

```bash
bun run build
claude mcp add council-dev /path/to/agents-council/dist/council mcp
```

## State Location During Dev

By default development shares the real `~/.agents-council/state.json`. To isolate dev runs:

```bash
export AGENTS_COUNCIL_STATE_PATH="$(pwd)/.dev-state/state.json"
```

`config.json` is created as a sibling automatically. This keeps experiments from polluting your real council history.

## Quality Gate (run before committing)

```bash
bun run lint
bun run typecheck
bun run format:check
bun test
```

Husky's `pre-commit` runs `lint-staged` (Biome on staged files) automatically; the commands above run the full set.
